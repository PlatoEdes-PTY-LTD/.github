## Hi, we're PlatoEdes 👋

We create practical, browser-based tools that are free, offline-friendly, and designed to make everyday work simpler.

From spreadsheet workflows to visual discussion tools, our projects focus on helping people think, organize, and create without installing software or creating accounts.

### Our projects

#### [Talika](https://github.com/PlatoEdes-PTY-LTD/Talika)
A free, offline, single-file web app for editing spreadsheets in the browser.

- Filter, sort, and manipulate tabular data
- Multi-tab spreadsheet workflows
- Works without a server or sign-up
- Built for lightweight, simple data handling

#### [DiscussionStudio](https://github.com/PlatoEdes-PTY-LTD/DiscussionStudio)
A free, offline browser app for visual discussions and idea mapping.

- Draw shapes and connect ideas
- Add notes and structure conversations visually
- Export to PowerPoint, PNG, or JSON
- Designed for brainstorming and collaborative thinking

### What matters to us

- Privacy-first software
- No installation headaches
- Offline-friendly experiences
- Tools that are useful in the real world
- Simplicity without sacrificing capability
